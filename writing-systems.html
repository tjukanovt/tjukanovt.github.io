Writing systems of the world's towns

Every coloured area is the land closest to a city or town in OpenStreetMap, painted by the script its local name is written in. Hover over the map to explore, or pick a script below to see where it is used.

    How this map was made

    Places tagged place=city or place=town in OpenStreetMap were taken from the Overture Maps divisions dataset (release 2026-11-18), keeping only features with an OpenStreetMap source. Each place's local name was assigned to the Unicode script that most of its letters belong to.

    Each town then got a Voronoi cell, the area closer to it than to any other town, computed on the sphere so that cells wrap the globe without distortion. Neighbouring cells with the same script were merged into the regions you see here.

    Japanese place names are mostly written in kanji, so they count as Han; only names with kana appear as Japanese kana. Bilingual names such as ⵜⴰⴷⴷⴰⵔⵜ ⵜⵓⵎⵍⵉⵍⵜ count towards whichever script has more letters. Large empty areas take the script of the nearest town.
